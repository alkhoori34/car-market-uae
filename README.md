# مِرْآب — سوق السيارات (نسخة احترافية)

هذا مشروع React حقيقي مبني بـ Vite، بدل الملف الواحد المستقل اللي كنا نستخدمه.
الفايدة: أداء أسرع، نشر تلقائي عند أي تعديل، ودعم نطاق مخصص لاحقًا.

## الخطوات (كل شي من المتصفح، بدون تثبيت أي برنامج)

### 1. ارفع المشروع على GitHub
1. افتح github.com وسجّل حساب مجاني (لو ما عندك)
2. اضغط **New repository** → سمّه مثلاً `car-market-uae` → اجعله **Public** أو **Private** → **Create repository**
3. بصفحة المستودع الفارغ، اضغط **"uploading an existing file"**
4. اسحب/ارفع **كل الملفات والمجلدات** اللي بهذا المشروع (بما فيها مجلد `src` كامل) إلا:
   - **لا ترفع** ملف `.env.example` القيم الحقيقية — خله كما هو (مثال فقط)
   - **لا يوجد** فولدر `node_modules` أصلًا هنا، فما تحتاج تستثنيه
5. اكتب رسالة commit بسيطة زي "أول رفعة" واضغط **Commit changes**

### 2. اربطه بـ Vercel
1. افتح vercel.com وسجّل دخول بحساب GitHub مباشرة (زر "Continue with GitHub")
2. اضغط **Add New → Project**
3. اختر مستودع `car-market-uae` اللي رفعته وامسح **Import**
4. Vercel بيتعرف تلقائيًا إنه مشروع Vite — خله كما هو
5. **قبل ما تضغط Deploy**، افتح قسم **Environment Variables** وأضف:
   - `VITE_SUPABASE_URL` = رابط مشروعك في Supabase
   - `VITE_SUPABASE_ANON_KEY` = مفتاح anon اللي عندك
6. اضغط **Deploy** — انتظر دقيقة، وبيعطيك رابط جاهز مثل `car-market-uae.vercel.app`

### 3. كل تعديل جاي
أي مرة تبي تعدّل الكود، عدّل الملف على GitHub مباشرة (أو من جهاز فيه Node.js لاحقًا)، و Vercel بينشر النسخة الجديدة تلقائيًا خلال ثوانٍ — بدون ما تحتاج ترفع ملفات يدويًا على Netlify كل مرة.

### 4. نطاق مخصص (لاحقًا)
من إعدادات المشروع في Vercel → **Domains** → أضف نطاقك (مثل `mirab.ae`) واتبع تعليمات ربط الـ DNS من مزوّد النطاق.
